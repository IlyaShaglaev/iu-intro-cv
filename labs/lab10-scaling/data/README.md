## Синтетическая гомография (TODO 1)

Для проверки `compute_homography_dlt` в ноутбуке создаётся повёрнутый и масштабированный кроп
с **известной** гомографией:

- Поворот: 15°
- Масштаб: 0.85
- Сдвиг: (0.08·w, 0.06·h)

Гомография строится как аффинное преобразование (поворот + масштаб + сдвиг), что является частным
случаем проективного преобразования. Четыре пары точек — углы кропа до и после преобразования —
вычисляются через `cv2.perspectiveTransform`. Это позволяет проверить, что DLT восстанавливает
гомографию с точностью до 10⁻⁶.

## Тесты ресайзера (TODO 2–3)

Для тестов цикла, композиции и коммутативности используется тот же кроп с текстурой. Стандартные
методы интерполяции (`cv2.INTER_LINEAR`, `cv2.INTER_CUBIC`, `cv2.INTER_LANCZOS4`) не являются
согласованными:

- **Цикл** ×2 → ×1/2 не возвращает оригинал (ошибка ~8.8·10⁻³ для билинейной, слайд 46)
- **Композиция** ×1/2 ×1/2 ≠ ×1/4 (ошибка ~7.2·10⁻⁴)
- **Коммутативность** порядок уменьшения по осям влияет на результат (ошибка ~2.2·10⁻³)

Эти ошибки малы, но не нулевые — именно это проверяют ассерты.

## Согласованное уменьшение (TODO 4)

Для проверки `consistent_downsample` используется правило σ ≈ 0.3 шага (из занятия 6):
для уменьшения в `scale` раз σ ≈ 0.3 · scale. Результат сравнивается с эталоном — уменьшением ×4
с повторным увеличением ×2 через `cv2.INTER_AREA` и `cv2.INTER_LINEAR`.

# HW3 — три автономных примера

`case1/`, `case2/`, `case3/` — собственные синтетические сцены курса, seed 10/11/12.
Каждая содержит четыре перекрывающихся кадра 340×180, известные преобразования
в `scene.json`, точные пары для DLT, опору/текстуру и AR-ролик из 12 кадров.
Файлы созданы средствами NumPy/OpenCV; внешних фотографий и загрузок нет.
`manifest.json` содержит реально вычисленные SHA-256 входных файлов.

Числа ниже измерены эталоном в окружении курса (OpenCV 4.14.0.94):

| Пример | DLT Frobenius | Панорама H×W | AR найдено/кадров |
|---|---:|---|---|
| case1 | 5.3925e-15 | 182×701 | 12/12 |
| case2 | 5.3925e-15 | 182×700 | 12/12 |
| case3 | 5.3925e-15 | 182×700 | 12/12 |

Известный геометрический холст по истинным H — 180×700. При оценке H по
детекторам округление границ холста может добавить 1–2 px. Проверяйте геометрию,
а не равенство размеров до пикселя между разными детекторами.
DLT-контроль должен проходить <1e-6; для проектирования точек тест использует
допуск 1e-9. На этих простых сериях ожидается доля инлаеров >0.8 и средняя
ошибка репроекции <1 px. AR должен обработать весь ролик и находить опору
хотя бы на 10 кадрах. Порогов FPS для этих файлов нет: скорость зависит от CPU.

Полный JSON-вывод каждого запуска — `case*/expected.json`, включая измеренные
тайминги как ориентир для машины подготовки. Примеры — контроль реализации;
они не воспроизводят сложность собственной съёмки и параллакса.
Команды запуска — в основном README. Для копии template перенесите сюда весь
каталог sample_data, чтобы тесты работали без сети.

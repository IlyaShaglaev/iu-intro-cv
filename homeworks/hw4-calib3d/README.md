## 1. Калибровка камеры

Соберите **20+ фотографий шахматной доски** на жёстком основании: разные наклоны,
позиции, расстояния, углы изображения. Выключите автофокус/цифровой зум и
сохраните одно разрешение. Укажите физический размер клетки **в метрах**.
По умолчанию 7×5 — внутренние углы, а не число клеток.

```powershell
python calib3d.py calibrate --images data/boards --columns 7 --rows 5 --square-m 0.03 -o out/camera.json
python calib3d.py calibrate --images data/boards --columns 7 --rows 5 --square-m 0.03 --max-error 0.8 -o out/camera-clean.json
```

Второй порог — пример аргумента, а не универсальная норма качества. Выберите
отбраковку по своим данным. ChArUco допустима вместо шахматки: добавьте детекцию
углов и соответствующих объектных точек, сохранив интерфейс `calibrate`.

Реализуйте `board_points`, `calibrate`, `reprojection_errors`: объектные точки,
вызов calibrateCamera, per-image RMS евклидовой 2D-ошибки в пикселях.
Покажите RMS до/после отбраковки, K/dist и его изменение при добавлении/удалении
снимков. Для визуализации используйте `undistort` или `initUndistortRectifyMap`.
Малая ошибка на одной плоской фронтальной позе не доказывает хорошую калибровку.

## 2. Метрология на плоскости

```powershell
python calib3d.py pose data/measurement-frame.png --calibration out/camera-clean.json -o out/pose.json
```

Команда `pose` находит шахматку, вызывает solvePnP и сохраняет K/dist/rvec/tvec.
Добавьте в копию этого JSON свои два пиксельных конца отрезка (`pixels`) и
известную длину (`truth_length_m`), затем передайте его команде `measure`.

Положите измеряемый отрезок на плоскость доски. Найдите позу через `solvePnP`
по углам доски и своей калибровке. Через `undistortPoints` постройте лучи,
пересеките их с Z=0 доски в `plane_measure`. **Объект вне плоскости** этим
методом корректно измерить нельзя. Измерьте отрезок рулеткой, сравните длину
и расстояние от центра камеры до начала СК доски (`||t||`); это не то же,
что её осевая координата `t_z`. Входной формат показан в `measure.json`.
Соберите таблицу «истина / измерено / относительная ошибка %» и объясните отказы.

## 3. Стерео и глубина

Реализуйте `sgbm`, `disparity_metrics`, `stereo_depth`, `point_cloud`.
На трёх базовых парах выполните сравнение нескольких параметров SGBM,
сохраните карту диспаратности, глубину и `.ply`; объясните смысл P1/P2,
numDisparities и blockSize. До тюнинга убедитесь в горизонтальности эпиполярных
линий. Базовые пары уже ректифицированы; GT относится к этим же координатам.
Свою неректифицированную пару сначала преобразуйте через `stereoRectify`/`remap`.

- Результат OpenCV `compute` делится **на 16**, а KITTI GT PNG — **на 256**.
- `bad2_pct`: доля ошибок **строго >2 px** на валидной GT-маске, в процентах.
  Неопределённый prediction на валидном GT считается ошибкой; coverage сообщается отдельно.
- RMSE — в пикселях на той же GT-области. Если есть пропуски предсказания,
  полный RMSE возвращается `null`; нельзя молча улучшать его удалением пропусков.
- `Z=fB/(d+doffs)`, B в метрах, f/d/doffs в пикселях. Невалидная диспаратность
  даёт NaN глубины и не экспортируется в облако.
- Выведите чувствительность `|ΔZ| ≈ Z²·|Δd|/(fB)` (для малой Δd); подтвердите
  численно на нескольких расстояниях. Сравните SGBM-глубину с GT-глубиной
  на выбранной области и сообщите покрытие, а не только красивую карту.

В отчёт включите выбранную конфигурацию и таблицу всех трёх примеров.
Одна выбранная конфигурация применяется к закрытым примерам без подстройки.
Собственная стереопара, stereoCalibrate и повторение пайплайна — ⭐ (+2 балла
по действующей программе); для базовой проверки две камеры не требуются.

## 4. Middlebury/KITTI — опциональное расширение

Исторический объём курса: **3 сцены Middlebury 2014 + 10 пар KITTI Stereo 2015**.
В этой выдаче внешние наборы **не обязательны для базового зачёта ДЗ** и не являются
предпосылкой ни одного теста. Все обязательные стерео-метрики можно посчитать на
трёх встроенных примерах. Расширение позволяет исследовать реальные отказы;
отсутствие аккаунта KITTI само по себе не снижает балл.

Выбор сцен/идентификаторов, ссылки, проверка доступности, локальный импорт и
подготовка данных описаны в [sample_data/README.md](sample_data/README.md).
`datasets/download.py` без аргументов ничего не скачивает. Опциональные загрузки
выбираются явно, с ожидаемой SHA-256; гигабайтные архивы автоматически не загружаются.
Внешние данные храните отдельно и не коммитьте в репозиторий.
